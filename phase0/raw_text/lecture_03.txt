Introduction to Linear Discriminant Analysis (LDA)
▶Deﬁnition: LDA is both a classiﬁcation and dimensionality reduction technique.
▶Core idea: Project data onto a lower-dimensional space (often 1D) that maximizes
class separability.
▶Typical Uses:
▶Face recognition
▶Medical diagnosis
▶Market research
▶Why LDA?
▶Simple, interpretable linear boundaries.
▶Often eﬀective when class distributions are approximately Gaussian.
▶Can reduce noise by focusing on most discriminative directions.

When to Use LDA
▶Two or more classes: LDA can handle multi-class classiﬁcation by ﬁnding multiple
discriminant components.
▶Data separability: Works well when classes are well-separated and covariance is similar
across classes.
▶Dimensionality reduction: When you need a lower-dimensional representation for

===== [PAGE 11] =====
When to Use LDA
▶Two or more classes: LDA can handle multi-class classiﬁcation by ﬁnding multiple
discriminant components.
▶Data separability: Works well when classes are well-separated and covariance is similar
across classes.
▶Dimensionality reduction: When you need a lower-dimensional representation for
further analysis or visualization.
▶Comparison to Other Methods:
▶Logistic Regression: Also linear, but does not reduce dimensionality.
▶Quadratic Discriminant Analysis (QDA): Allows diﬀerent covariance matrices per class,
but is more complex.
▶Nearest Neighbors: Non-parametric, can be less interpretable in high dimensions.
▶Principal Component Analysis (PCA): Unsupervised, focuses on variance rather than
class separation.

===== [PAGE 14] =====
Key Assumptions of LDA
1. Normality: Data in each class is drawn from a Gaussian (normal) distribution.
2. Identical Covariance: All classes share the same covariance matrix Σ.
3. Statistical Independence of Features: Usually assumed, though in practice mild
correlations are tolerated.
Implications:
▶If the covariance structures diﬀer signiﬁcantly between classes, Quadratic Discriminant
Analysis (QDA) may be more appropriate.
▶Violations of normality often do not drastically harm LDA, but may reduce its optimality.

Implementing LDA in Scikit-learn
▶Key Class:
▶LinearDiscriminantAnalysis from sklearn.discriminant_analysis.
▶Common Parameters:
▶solver: e.g. svd, lsqr, or eigen.
▶shrinkage: can improve robustness when data is limited or covariance matrices are
ill-conditioned.
▶n_components: controls dimensionality reduction (<= number of classes - 1).
▶Basic Usage:
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
lda = LinearDiscriminantAnalysis(solver=’svd’, n_components=1)
lda.fit(X_train, y_train)
predictions = lda.predict(X_test)
▶Model Attributes:
▶lda.coef_: Class-wise linear coeﬃcients.
▶lda.explained_variance_ratio_: Variance explained by each discriminant component.
▶lda.means_: Class means.

Practical Tips and Summary
▶Data Preprocessing:
▶Scale or standardize features for more stable covariance estimation.
▶Verify no extreme multicollinearity issues.
▶Model Evaluation:
▶Use cross-validation to compare accuracy or other metrics.
▶Check confusion matrices for class-level performance.
▶When LDA Shines:
▶Moderate to large datasets where class distributions are somewhat separable.
▶Preprocessing step for dimensionality reduction (visualization or feeding to other models).
▶Key Takeaway: LDA is a powerful, interpretable linear approach for classiﬁcation and
dimension reduction, especially under roughly Gaussian assumptions with shared
covariance.

▶Goal: Reduce model overﬁtting by penalizing large coeﬃcients.
▶Idea: Add a penalty term to the cost function ∑(y −ˆy)2.
▶Key beneﬁts:

▶Some methods also perform feature selection.

Ridge (ℓ2):
▶Coeﬃcients get shrunk but not set to

===== [PAGE 23] =====
Choosing the Regularization Parameter λ
▶λ (or λr, λℓ, etc.) controls the penalty strength:
▶λ = 0 →reverts to ordinary least squares (no penalty).
▶λ →∞→shrinks all coeﬃcients toward 0.
▶Cross-Validation:
▶Systematically vary λ over a grid of values.
▶Evaluate prediction error (MSE, MAE, etc.) on the validation set.
▶Pick λ that minimizes validation error or has the best trade-oﬀ(e.g., 1-SE rule).
▶Practical Tips:
▶Standardize features before applying regularization to ensure fair coeﬃcient shrinkage.
▶Watch for high correlation among features (especially for Lasso).

from sklearn.linear_model import Ridge

▶Hyperparameter Tuning:
▶Use GridSearchCV or RandomizedSearchCV to ﬁnd the best α.
▶For ElasticNet, tune both α (mixing ratio) and λ.
▶Common Pitfalls:
▶Forgetting to scale data can bias penalty terms.
▶Over-penalizing: too high λ can underﬁt.
