Recap: Linear Discriminant Analysis (LDA)
▶Purpose:
▶Supervised classiﬁcation & dimensionality reduction.
▶Projects data onto a lower-dimensional space to maximize class separation.
▶When to Use:
▶Two or more well-separated classes with similar covariance matrices.
▶Need for interpretable linear boundaries and reduced dimensionality.
▶Mathematical Core:
▶Deﬁnes scatter matrices: SB (between-class) and SW (within-class).

Recap: LDA Assumptions & Practical Tips
▶Key Assumptions:
1. Each class follows (approximately) a normal (Gaussian) distribution.
2. All classes share the same covariance matrix.
3. Features are ideally uncorrelated, but mild correlations are often acceptable.
▶Implications:
▶If covariances diﬀer signiﬁcantly, consider Quadratic Discriminant Analysis (QDA).
▶LDA can be robust to mild violations of normality.
▶Practical Tips:
▶Scale/standardize data to stabilize covariance estimation.
▶Use cross-validation to evaluate classiﬁcation performance (e.g., confusion matrices).
▶Works well with moderate-to-large datasets that have reasonable class separation.
▶Takeaway: A simple, interpretable linear boundary with dimensionality reduction under
Gaussian assumptions.

Recap: Regularized Regression (Ridge, Lasso, Elastic Net)
▶Motivation: Mitigate overﬁtting by penalizing large coeﬃcients.
▶Methods Overview:
▶Ridge (L2):
▶Shrinks coeﬃcients (rarely to exactly zero).
▶Useful for handling multicollinearity.
▶Lasso (L1):
▶Can set some coeﬃcients to zero (feature selection).
▶Often helpful in high-dimensional settings.
▶Elastic Net (L1 + L2):
▶Balances the strengths of Ridge and Lasso.
▶Two hyperparameters: overall strength (λ) + mixing ratio (α).
▶Choosing λ:
▶Use cross-validation to ﬁnd the best bias-variance trade-oﬀ.
▶Standardize features before applying the penalty terms.
▶Key Takeaway: Regularization improves generalization, reduces overﬁtting, and can do
feature selection (Lasso/Elastic Net).

===== [PAGE 19] =====
Decision Trees
▶A non-parametric method for classiﬁcation and regression.
▶The data is repeatedly split into subsets based on feature thresholds, growing a tree
structure.
▶Each split is chosen to maximize the purity of the resulting subsets (minimize impurity).
▶Advantages: Interpretability, handles mixed feature types, no need for feature scaling.
▶Drawbacks: Can overﬁt if not pruned, can be unstable (high variance) for small data.
Vegard Høghaug Larsen: Lecture 4:, Classiﬁcation Analysis

▶Choose a feature + threshold to best split the data (based on impurity).
▶Split the data into two (or more) subsets.
▶Repeat the process on each subset until a stopping criterion is met.

===== [PAGE 21] =====
Training a Decision Tree
▶Constructed recursively:
▶Choose a feature + threshold to best split the data (based on impurity).
▶Split the data into two (or more) subsets.
▶Repeat the process on each subset until a stopping criterion is met.
▶Stopping criteria:
▶Maximum depth reached.
▶Fewer samples in a node than the minimum required for a split.
▶Impurity improvement is below a certain threshold.
