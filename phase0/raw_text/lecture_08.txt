What is Gradient Descent?
▶An optimization algorithm to minimize a loss function by iteratively moving in the
direction of steepest descent (negative gradient).
▶Update rule: For a parameter w,
w ←w −η ∇wL,
where η is the learning rate (step size).
▶Objective: ﬁnd parameters that minimize the loss (error) on training data, by
continuously updating weights opposite to the gradient.

===== [PAGE 5] =====
Gradient Descent Variants
▶Batch Gradient Descent: Compute gradient on the entire dataset before each update
- stable but can be very slow for large data.
▶Stochastic Gradient Descent (SGD): Compute gradient on a single example at a
time - much faster updates but noisier (updates may ﬂuctuate).
▶Mini-Batch Gradient Descent: Compute gradient on a small batch of examples (e.g.
32 or 64) - a compromise that oﬀers faster convergence than full-batch and more
stability than pure SGD.
▶In practice, mini-batches are most common (e.g. 32 samples per update) to leverage
vectorized computation and achieve good convergence.

Computational Graphs: automatic diﬀerentiation
▶In the above example the loss function L is a function of the parameters w1 and w2. In a
neural network, the loss is a function of all the weights and biases in the network.
▶We can then look at Neural networks as large computational graphs: input ﬂows forward
through layers to compute output, and we can trace how each weight inﬂuences the
ﬁnal loss.
▶Deep learning frameworks (e.g. PyTorch, TensorFlow) build these graphs during the
forward pass, recording operations and their inputs/outputs.
▶This sets the stage for automatic diﬀerentiation.
▶Automatic diﬀerentiation is a technique to compute the gradient of a function with
respect to its inputs automatically using the chain rule.

composition of many functions, gradients multiply along the chain.
▶In a computational graph, the chain rule allows us to propagate gradients backward: the
gradient of a node’s output w.r.t. some input equals the product of gradients along the
path from input to output.
▶Local Gradients: Each operation knows how its output changes w.r.t. its inputs.
Backpropagation uses these local derivatives and the chain rule to get global gradients.
▶Key idea: Backpropagation boils down to applying the chain rule repeatedly on a
graph of computations.

What is Backpropagation?
▶Backpropagation = backward propagation of errors - the core algorithm that computes
the gradient of the loss with respect to all parameters in the model.
▶It is essentially an eﬃcient application of the chain rule on the computational graph of
the model’s forward pass. It allocates portions of the output error to each weight by
traversing the graph in reverse.
▶Forward pass: compute outputs and loss using current weights.
▶Backward pass: starting from the loss, propagate the error gradient backward through
each operation (layer) to ﬁnd ∂L
∂w for every weight w.
▶The result is the gradient vector given by ∇θL (partial derivatives of loss w.r.t. each
parameter collected in a vector θ). We use this to update weights (e.g. using gradient
descent).

===== [PAGE 15] =====
Training with Backprop + Gradient Descent
Combine backprop with an iterative training loop: for each epoch (and for each batch of
data):
▶Forward pass: compute predictions and loss
▶Backward pass: compute gradients via backpropagation
▶Update weights: w ←w −α∇wL for all weights (using the chosen gradient descent
variant)
▶Batch GD: use all training data to compute an average gradient, then update once per
epoch.
▶Stochastic GD: update for each training example (one forward/backward per example).
▶Mini-batch GD: update for each small batch (common in practice, e.g. 32 samples gives
a good balance).
Iterate for many epochs - the loss typically decreases and the model improves.
Backpropagation ensures each weight is nudged in the direction that most reduces the error.
Outcome: The network’s weights gradually converge to values that produce low loss (i.e., the
network learns from the data).

Step 1. Updating the weights
ADALINE rule
1. We initialize the weights and bias;
2. We compute the NET INPUT: z(i) = w⊤x(i) + b;
3. We compute the error in the training step BY y(i) −z(i), where now y(i) ∈{0, 1} but
z(i) takes values in all R;
Since we want to minimize the diﬀerence y(i) −z(i):
▶For those x(i) corresponding to y(i) = 1, the weights w and b needs to push z(i) as
closed as possible to 1;
▶For those x(i) corresponding to y(i) = 0, the weights w and b needs to push z(i) as
closed as possible to 0.
