Ensemble methods
▶A family of techniques that involve training multiple models and combining their
predictions to form a more accurate and robust model
▶Can be used with a variety of models (e.g. linear models, decision trees, or neural
networks)
▶By combining multiple models, the ensemble typically reduces variance and often boosts
performance
▶A trade-oﬀ: ensembles are often more powerful, but can be less interpretable than
single models

Bagging
▶Bagging is short for Bootstrap AGGregatING
▶Train multiple instances of a base model on bootstrap samples of the training data
▶Combine their predictions (via majority vote or averaging) to form a ﬁnal prediction
▶Subsets are created using sampling with replacement
▶Eﬀective at reducing variance and mitigating overﬁtting for high-variance base learners
(e.g., large decision trees)
Vegard Høghaug Larsen: Lecture 7:, Ensemble Methods
6/21

===== [PAGE 10] =====
Bootstrap in Machine Learning
▶A resampling technique to approximate the sampling distribution of a statistic
▶Repeatedly sample with replacement to create new datasets of the same size as the
original
▶About 63% of unique samples from the original dataset typically appear in each
bootstrap sample
▶Used to train multiple models (bagging) or provide performance estimates (e.g. OOB
error)
▶Especially useful for small datasets or when data is expensive to collect

How does bagging work?
▶Create multiple bootstrap samples of the training data
▶Train a base model (e.g. a decision tree) on each bootstrap sample
▶Use each trained model to make predictions
▶Combine predictions from all models (majority vote for classiﬁcation or averaging for
regression)
▶Final prediction often has lower variance and improved generalization

Boosting
▶A technique that combines multiple weak learners sequentially
▶Each subsequent model focuses more on samples that previous models misclassiﬁed
(higher weight)
▶Typically reduces bias, but can be prone to overﬁtting if not regularized
▶Often uses simpler base learners (e.g. shallow trees), which are incrementally improved
Vegard Høghaug Larsen: Lecture 7:, Ensemble Methods
11/21

===== [PAGE 15] =====
How does boosting work?
1. Initialize the weights of each training example equally
2. Train a base model on the training data using the current weights
3. Evaluate performance on the training data
4. Increase weights of misclassiﬁed examples and decrease weights of correctly classiﬁed
examples
5. Repeat until stopping criterion (e.g. max iterations or minimal improvement)
6. Final prediction is a weighted combination of all models’ predictions
7. Learning rate (η) often controls the contribution of each weak learner

Recap: Decision trees
▶Built by recursively splitting data into subsets based on a feature threshold that provides
the best information gain
▶Leaf nodes contain ﬁnal predictions (class labels or numeric values)
▶Advantages: easy to interpret, handle mixed data types, minimal preprocessing
▶Disadvantages: prone to overﬁtting if unpruned, can be unstable w.r.t. small data
changes

===== [PAGE 21] =====
Decision trees →Random forests
▶Bagging multiple decision trees alone can lead to highly correlated trees
▶Random Forest adds feature randomness to reduce correlation among trees
▶In addition to bootstrapping samples, each split considers only a random subset of
features
▶Reduces variance by decorrelating trees; improves predictive performance
Vegard Høghaug Larsen: Lecture 7:, Ensemble Methods
18/21

===== [PAGE 22] =====
De-correlated trees
1. Each tree is built from a bootstrapped subset of the training data
2. At each split, randomly select a set of predictors (e.g. √p) out of p
3. From these predictors, choose the best predictor and threshold
4. Result: lower correlation among trees and often higher accuracy
Vegard Høghaug Larsen: Lecture 7:, Ensemble Methods
19/21

===== [PAGE 23] =====
Random forests
▶Each decision tree in the ensemble is trained on a unique bootstrap sample
▶Within each tree, only a subset of features is considered for splits
▶Final classiﬁcation prediction by majority vote; for regression, often averaged
▶Provides good performance out-of-the-box and can handle large feature spaces
Vegard Høghaug Larsen: Lecture 7:, Ensemble Methods

===== [PAGE 24] =====
Extra trees
▶Stands for Extremely Randomized Trees
▶Similar to Random Forest in that multiple trees are trained on bootstrap samples
▶At each node, a random subset of features is chosen (like in RF)
▶Key diﬀerence: Extra Trees picks random splitting thresholds, rather than searching for
the optimal threshold
