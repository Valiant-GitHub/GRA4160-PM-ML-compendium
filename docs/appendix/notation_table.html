Notation

Why this page exists. The course decks reuse a handful of letters for very different quantities — sometimes within a single lecture. This table fixes one convention per concept, anchored to ESL (per GR1), and flags the collisions so every method page can say which meaning is in play. Where the course writes a symbol differently, the course form is noted as “see also” — the professor grades by the slide convention.

Master symbol table

The chosen column is what this site uses consistently. The course usage column records the slide/notebook symbol and any collision.

The five disambiguations to watch site-wide

  1. k / K — the worst offender. Resolved by role-specific letters: K neighbors, d parameters, V folds, K clusters, K hidden units. Every math header names its local k.
  2. p = probability vs #predictors — this site uses \pi for probability (slides write p).
  3. sklearn alpha = \lambda (penalty strength), not the Elastic-Net \alpha (that is l1_ratio). The single most common regularization bug — flagged on the Regularization page.
  4. \eta vs \alpha for learning rate — standardized on \eta.
  5. \delta: update step vs error signal — standardized on ESL’s error signal \delta; the update step is \Delta\theta.

Symbols the course leaves implicit (supplied from ESL/ISL, marked supplemental)

  • PCA principal-component vectors / eigenvalues — not symbolized on L6 slides → ESL §14.5 (v_j, d_j).
  • AdaBoost stage weight \alpha_m = \tfrac12\ln\frac{1-\text{err}}{\text{err}} — not on L7 slides → ESL §10.1.
  • Random-forest regression feature-subset default m\approx p/3 — only \sqrt p on slides → ISL §8.2.
