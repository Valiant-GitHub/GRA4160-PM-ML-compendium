GRA 4160 — Machine Learning Study Companion

A practical take-home study companion & post-exam reference

BI Norwegian Business School — GRA 4160, Predictive Modelling with Machine Learning. Built from the course’s own lecture slides and notebooks, with The Elements of Statistical Learning (ESL) and An Introduction to Statistical Learning (ISL) as reference anchors. Every claim, formula, and code idiom traces to a real source file.

What this is

This is a practical study companion for the GRA 4160 take-home exam, and a reference to keep open while you work. The exam is a 30-hour, open-resource, notebook-based take-home: you load data, choose methods, write and run code, and—crucially—justify every choice. The course grades your reasoning as heavily as your result. So the centre of gravity here is practitioner thinking: when to reach for which method, what code to actually write, and how to read the output you get back. The full mathematics is preserved at two levels of rigor, but tucked behind a toggle so it never crowds out the practical thread.

There are two ways to read it. Browse by problem: use the decision dashboard below to go from “what does my data look like?” to a short, ranked list of methods with links straight to their pages. Or read straight through: the sidebar walks the methods in concept-progression order (OLS → kNN → logistic → LDA → … → neural nets), each page following the same eight-section template. Independently, the math toggle in the top bar cycles through three states — off (prose and code only), course level (the math the course actually teaches and grades), and full (complete derivations anchored to ESL). Your choice is remembered across pages.

Beyond the per-method pages, the cross-method layer is where method selection lives: family-comparison tables, head-to-head showdowns (same dataset, several methods, what to notice), and the interactive dashboard. The drill section works the actual past-exam questions and the course exercise notebooks end-to-end — not as code dumps, but as the decisions and idioms a strong take-home answer would use. Start with the dashboard if you have a dataset in mind; start with Reading the Data if you want the diagnostic habits that drive every later choice.

How the math toggle works

Use the Math control in the top bar to cycle off → course level → full. The two boxes below appear and disappear accordingly (try it):

Math is currently off — switch the top-bar toggle to “course level” or “full” to reveal the derivations.

Mode A — course level. OLS minimizes the residual sum of squares; the closed-form solution is \hat{\beta} = (X^\top X)^{-1} X^\top y.

Mode B — full rigor. The normal equations follow from setting \nabla_\beta \lVert y - X\beta\rVert_2^2 = -2X^\top(y - X\beta) = 0, giving X^\top X \hat\beta = X^\top y; when X^\top X is invertible this is the unique global minimizer (the objective is convex with Hessian 2X^\top X \succeq 0).
