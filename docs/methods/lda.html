Linear Discriminant Analysis (LDA)

Linear family · the supervised cousin of PCA: one model that does both classification and dimensionality reduction by projecting onto the directions that pull the classes apart. Siblings: Logistic Regression (also a linear classifier, but no dimensionality reduction and fewer distributional assumptions), QDA (one covariance per class), PCA (unsupervised — variance, not class separation), kNN (non-parametric alternative).

1. Essence

Linear Discriminant Analysis takes labelled data and finds the direction(s) along which the classes are most cleanly separated, then either reports a class for each point (classifier) or hands back the low-dimensional projection (dimensionality reduction). The guiding idea is a single trade-off, the Fisher criterion: choose the projection that makes the class means sit far apart (large between-class variance) while each class stays tight around its own mean (small within-class variance) (Lecture 3, slide 8/20; notebook 04_Linear_discriminant_analysis.ipynb, cell 2). Because that projection is a linear combination of the features, the resulting decision boundary is a straight line (or hyperplane), and a C-class problem yields at most C-1 useful discriminant directions — which is why two classes collapse to a single axis.

It is a parametric, generative model: it assumes each class is drawn from a Gaussian and — crucially — that all classes share one covariance matrix (Lecture 3, slide 10/20). Under those assumptions LDA is the Bayes-optimal linear classifier; it trains in essentially one pass (estimate the class means, the pooled covariance, and the priors), needs little data, and gives an interpretable boundary. The shared-covariance assumption is exactly what makes the boundary linear — relax it (one covariance per class) and you get the quadratic boundary of QDA instead.

LDA wears two hats at once, which is its distinctive feature. As a classifier it competes with logistic regression: both are linear, but LDA commits to the Gaussian/shared-covariance story while logistic regression models the log-odds directly and makes fewer distributional assumptions (Lecture 3, slide 11/20). As a dimensionality reducer it competes with PCA: PCA keeps the directions of greatest total variance ignoring labels, whereas LDA — being supervised — keeps the directions of greatest class separation (Lecture 3, slide 7/20).

2. When to use / when not to use

Reach for LDA when…

  • The target is a class and you have two or more reasonably well-separated classes whose spreads (covariances) look similar (Lecture 3, slide 7/20).
  • You want an interpretable linear boundary and/or a supervised low-dimensional view of the data — LDA gives you both from one fit. On Iris it compresses 4 features to 2 discriminants that visibly separate the three species (see §4).
  • You want a fast, low-variance baseline classifier that needs little data — the model is just class means, a pooled covariance, and priors.
  • You plan to feed a downstream classifier a cheaper representation: LDA is “frequently used as a preprocessing step before applying classifiers like logistic regression” (notebook 04_…, cell 4).

Reach for something else when…

  • The classes have clearly different covariances (different shapes/orientations) → the shared-covariance assumption is wrong and the linear boundary underfits. Use QDA, which estimates a separate covariance per class and gives a quadratic boundary (Lecture 3, slide 10/20).
  • You want minimal distributional assumptions for a linear classifier → Logistic Regression models the log-odds directly without assuming Gaussian features; it is often the safer default when normality is doubtful (Lecture 3, slide 11/20).
  • You want dimensionality reduction but have no labels (or care about variance, not separation) → PCA is the unsupervised counterpart; LDA cannot run without y (it is supervised — “it requires the class labels to be passed … in the fit method”, notebook 04_…, cell 14).
  • The boundary is clearly non-linear → kNN or Decision Trees / Random Forests drop the linear-form assumption (more flexible, less interpretable, hungrier for data).

3. Code idiom

The canonical course idiom is scikit-learn’s LinearDiscriminantAnalysis; the course also builds LDA from scratch via the eigendecomposition of S_W^{-1}S_B so the Fisher criterion is not a black box.

Canonical (sklearn) — (notebook 04_Linear_discriminant_analysis.ipynb, cell 8)

from sklearn.discriminant_analysis import LinearDiscriminantAnalysis

# n_components: number of discriminant axes to keep after transform; must be ≤ #classes − 1
lda = LinearDiscriminantAnalysis(n_components=1)   # 2-class toy data → at most 1 discriminant
lda.fit(X_train, y_train)                          # supervised: labels are REQUIRED
X_transformed = lda.transform(X_train)             # project onto the discriminant axis (dim reduction)
lda.predict(X_test)                                # class labels (classification)
lda.score(X_test, y_test)                          # mean accuracy

For multi-class dimensionality reduction the only change is n_components (notebook 04_…, cell 15) — and fit_transform does fit-then-project in one call:

lda = LinearDiscriminantAnalysis(n_components=2)   # 3-class Iris → up to 2 discriminants (LD1, LD2)
X_train_lda = lda.fit_transform(X_train2, y_train2)  # fit on train, return its projection
X_test_lda  = lda.transform(X_test2)                 # project test with the SAME learned axes

The hyperparameters worth knowing (Lecture 3, slide 11/20): solver ∈ {svd (default, no covariance inversion, good for many features), lsqr, eigen}; shrinkage (regularizes the covariance estimate, only with lsqr/eigen); and n_components (the projection dimension, capped at #classes − 1). In notebook 04_… everything except n_components is left at its default. Useful attributes: coef_, means_, explained_variance_ratio_. Tip stressed in lecture: scale/standardize features first (Lecture 3, slide 11/20; Lecture 4, slide 4/11).

From scratch — eigendecomposition of S_W^{-1}S_B (notebook 04_…, cell 18; this is the Tier-1 variation that fills the gap cell 4 leaves: “we will not dive into all the mathematical details”). The heart of the class is: build the within- and between-class scatter, then take the eigenvectors of \Sigma^{-1}S_B:

# within-class scatter S_W (sum of per-class outer products), then pooled covariance
S_W = np.zeros((n_features, n_features))
for c in self.classes_:
    X_c = X[y == c]; mean_c = self.means_[c].reshape(-1, 1)
    for x in X_c:
        x = x.reshape(-1, 1)
        S_W += (x - mean_c) @ (x - mean_c).T
self.cov_ = S_W / (n_samples - len(self.classes_))   # unbiased pooled cov, "consistent with sklearn"

# between-class scatter S_B = Σ_c N_c (μ_c − μ)(μ_c − μ)ᵀ
S_B = np.zeros((n_features, n_features))
for c in self.classes_:
    mean_diff = self.means_[c].reshape(-1, 1) - self.overall_mean_
    S_B += self.class_count_[c] * (mean_diff @ mean_diff.T)

# generalized eigenproblem: discriminant axes = top eigenvectors of inv(Σ) @ S_B
A = np.linalg.inv(self.cov_) @ S_B
eigvals, eigvecs = np.linalg.eig(A)
idx = np.argsort(np.real(eigvals))[::-1]      # sort eigenvalues descending
self.W_ = np.real(eigvecs)[:, idx][:, :self.n_components]   # keep top n_components

Idiom variation worth knowing. The from-scratch predict does not project-then-threshold; it applies the Gaussian/Bayes discriminant rule directly, \delta_c(x) = x^\top\Sigma^{-1}\mu_c - \tfrac12\mu_c^\top\Sigma^{-1}\mu_c + \log\pi_c, and takes the argmax over classes (notebook 04_…, cell 18). This is the same maximum-a-posteriori rule sklearn uses, which is why the two implementations agree to the digit on the toy set (see §4). If you ever quote the from-scratch test accuracy, recompute it — the notebook does not store that number (phase0/disagreements.md [NB-10]); the value below was computed in the venv.

4. Worked examples

Example 1 — toy 2-class set: classifier accuracy, sklearn vs from-scratch

The course generates a 2-feature, 2-class toy set and fits LDA as a classifier (notebook 04_…, cell 6):

X, y = make_classification(n_samples=200, n_features=2, n_redundant=0, n_informative=2,
                           n_clusters_per_class=1, class_sep=0.75, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.33, random_state=42)
LinearDiscriminantAnalysis(n_components=1).fit(X_train, y_train).score(X_test, y_test)

The stored notebook output is a test accuracy of 0.7424 (notebook 04_…, cell 13, stored output 0.7424242424242424). The modest score is the point, not a bug: class_sep=0.75 makes the two Gaussians overlap substantially, so even the Bayes-optimal linear boundary cannot do much better — a vivid reminder that accuracy is bounded by how separable the classes actually are, not by the model’s effort.

The from-scratch LDAFromScratch(n_components=1) (cell 18–19), fit on the same split, reaches the identical test accuracy of 0.7424 (train accuracy 0.7910 for both) — computed in the venv (./.venv/Scripts/python.exe, random_state=42), resolving the [VERIFY] flag in phase0/disagreements.md [NB-10]. The agreement is by design: both use the pooled (unbiased) covariance S_W/(n-C) and the same Bayes discriminant rule, so they are the same classifier, just coded twice. The single non-trivial eigenvalue of \Sigma^{-1}S_B is ≈ 77.4 (the second is numerically zero — there is only C-1 = 1 discriminant for two classes), computed in the venv.

This is the natural place to line LDA up against logistic regression: on a 2-class problem both draw a straight boundary, but LDA assumes the two clouds are Gaussian with a shared covariance whereas logistic regression just fits the log-odds. When that assumption roughly holds (as here, by construction), they land in the same neighbourhood; when it fails badly, logistic regression usually degrades more gracefully. See the 2D classification showdown.

Example 2 — Iris: LDA as supervised dimensionality reduction

On Iris (150 samples, 4 features, 3 species) LDA wears its other hat — squashing 4 features to 2 discriminants for visualization (notebook 04_…, cell 15):

iris = load_iris(); X2, y2 = iris.data, iris.target
X_train2, X_test2, y_train2, y_test2 = train_test_split(X2, y2, test_size=0.2, random_state=10)
lda = LinearDiscriminantAnalysis(n_components=2)     # 3 classes → up to 2 discriminants
X_train_lda = lda.fit_transform(X_train2, y_train2)  # LD1, LD2 for the training set
X_test_lda  = lda.transform(X_test2)

The first discriminant carries almost everything: explained_variance_ratio_ ≈ [0.992, 0.008] — LD1 alone accounts for ~99.2 % of the between-class separation (computed in the venv, random_state=10). In the LD1–LD2 scatter the three species fall into cleanly separated bands, with setosa far from the other two. As a classifier on this split the same model scores 0.975 train / 1.00 test accuracy (computed in the venv) — but with only 30 test points the perfect test score is small-sample luck, not a claim that Iris is trivially separable; report it as “high” rather than overreading the exact 1.00.

Contrast with PCA on the same Iris data: PCA would pick the 2 directions of largest total variance ignoring the species labels, which need not be the directions that separate species. LDA’s 99.2 %-on-LD1 result is precisely what supervision buys you — it spends its budget on class separation, not raw spread. This is the canonical “supervised vs unsupervised dimensionality reduction” comparison.

6. Diagnostics & interpretation

What to report and look at to decide whether an LDA model is working:

  • Accuracy / confusion matrix — LDA is a classifier first; report test accuracy (toy: 0.74) and, for multi-class, the confusion matrix to see which classes get confused (Lecture 4, slide 4/11 explicitly recommends confusion matrices).
  • explained_variance_ratio_ — for the dimensionality-reduction hat, this tells you how much class separation each discriminant captures (Iris: LD1 ≈ 99.2 %). A first discriminant near 1.0 means a 1D view loses almost nothing.
  • Check the shared-covariance assumption — if the classes visibly have different shapes/orientations, the linear boundary is mis-specified; that is the cue to move to QDA. Mild non-normality is usually tolerable (“robust to mild normality violations”, Lecture 4, slide 4/11).
  • Did you standardize? — scaling is stressed twice in lecture (L3 slide 11, L4 slide 4); on raw features with very different units the pooled covariance can be dominated by one feature.

Comparative diagnostic vs siblings: LDA gives you a generative story (class means + a shared covariance + priors), so you can read off how it would generate each class — where logistic regression gives only a discriminative boundary (the log-odds), and PCA gives variance-ranked axes with no notion of class at all. Choose the model whose output answers your question: “which class, and why” (LDA), “what are the odds” (logistic), or “what varies most” (PCA).

8. Math

Math is off. Use the Math toggle in the top bar to show the course-level derivation (and “full” for the rigorous version).

Mode A — course level. The course frames LDA through Fisher’s criterion: find the projection direction w that pushes the class means apart while keeping each class tight (notebook 04_Linear_discriminant_analysis.ipynb, cell 2; Lecture 3, slide 8/20). Write the between-class and within-class scatter matrices S_B = \sum_{i=1}^{C} N_i\,(m_i-m)(m_i-m)^\top, \qquad S_W = \sum_{i=1}^{C}\sum_{x\in C_i}(x-m_i)(x-m_i)^\top, where m_i = \tfrac{1}{N_i}\sum_{x\in C_i} x is the mean of class i (size N_i) and m is the overall mean (slide 9/20). Fisher’s criterion is the ratio of projected between- to within-class variance, which we maximize: w = \arg\max_w \frac{w^\top S_B\, w}{w^\top S_W\, w}. Reading it: the numerator w^\top S_B w is how far apart the class means look after projecting onto w; the denominator w^\top S_W w is how spread out each class looks along w — so the ratio rewards separation and penalizes overlap. Setting the gradient of this ratio to zero turns it into a generalized eigenproblem whose top eigenvectors are the discriminant axes: S_W^{-1}S_B\, w = \lambda w \qquad \text{(cell 3; slide 9/20).} For two classes this collapses to a single closed form (only C-1=1 axis exists), and because S_B then has rank one the direction is simply w \propto S_W^{-1}(m_1-m_2) \qquad \text{(Lecture 3, slide 9/20)} — the line joining the two means, “rotated” by S_W^{-1} to undo the within-class spread. Local notation note (per phase0/notation_table.md): here \lambda denotes an LDA eigenvalue (not a regularization strength), m_i the class mean, N_i the class size, and w the discriminant direction (not a generic weight vector). See the linear-algebra appendix.

Mode B — full rigor. (Anchored to ESL §4.3, eqs 4.7–4.12 and 4.15–4.16; verified at PDF pp. 126–135 = printed pp. 106–116.) ESL derives LDA from decision theory, not from Fisher’s ratio. Let f_k(x) be the class-conditional density and \pi_k the prior of class k (with \sum_k\pi_k=1). Bayes’ theorem gives the posterior \Pr(G=k\mid X=x) = \frac{f_k(x)\,\pi_k}{\sum_{\ell=1}^K f_\ell(x)\,\pi_\ell} \qquad \text{(ESL 4.7),} so classifying to the largest posterior is Bayes-optimal. Now model each class as a multivariate Gaussian f_k(x) = \frac{1}{(2\pi)^{p/2}\lvert\Sigma_k\rvert^{1/2}}\,\exp\!\Bigl(-\tfrac12 (x-\mu_k)^\top\Sigma_k^{-1}(x-\mu_k)\Bigr) \qquad \text{(ESL 4.8).} LDA is the special case of a shared covariance \Sigma_k=\Sigma\ \forall k. Comparing two classes by their log-posterior ratio, \log\frac{\Pr(G=k\mid x)}{\Pr(G=\ell\mid x)} = \log\frac{\pi_k}{\pi_\ell} - \tfrac12(\mu_k+\mu_\ell)^\top\Sigma^{-1}(\mu_k-\mu_\ell) + x^\top\Sigma^{-1}(\mu_k-\mu_\ell) \qquad \text{(ESL 4.9),} which is linear in x: the shared \Sigma makes the normalizing constants and the quadratic term x^\top\Sigma^{-1}x cancel between the two classes. The boundary \{x:\Pr(G=k\mid x)=\Pr(G=\ell\mid x)\} is therefore a hyperplane. Equivalently, classify by G(x)=\arg\max_k \delta_k(x) using the linear discriminant functions \delta_k(x) = x^\top\Sigma^{-1}\mu_k - \tfrac12\mu_k^\top\Sigma^{-1}\mu_k + \log\pi_k \qquad \text{(ESL 4.10)} — exactly the rule the from-scratch predict implements (notebook 04_…, cell 18), with the plug-in estimates \hat\pi_k=N_k/N, \hat\mu_k=\sum_{g_i=k}x_i/N_k, and the pooled covariance \hat\Sigma=\sum_{k}\sum_{g_i=k}(x_i-\hat\mu_k)(x_i-\hat\mu_k)^\top/(N-K) (the N-K denominator is why the notebook’s S_W/(n−C) “matches sklearn”). Why this matters: QDA. If the \Sigma_k are not assumed equal, the quadratic term survives and you get the quadratic discriminant \delta_k(x)=-\tfrac12\log\lvert\Sigma_k\rvert-\tfrac12(x-\mu_k)^\top\Sigma_k^{-1}(x-\mu_k)+\log\pi_k (ESL 4.12) — a curved boundary. Shared covariance ⇔ linear; per-class covariance ⇔ quadratic.

Equivalence to Fisher’s criterion. ESL §4.3.3 shows the Mode-A view is the same model. Writing B for the between-class covariance of the centroids and W for the within-class (pooled) covariance, Fisher’s “maximize between- over within-class variance” is the Rayleigh quotient \max_a \frac{a^\top B\, a}{a^\top W\, a} \qquad \text{(ESL 4.15)} \quad\Longleftrightarrow\quad \max_a a^\top B\, a \ \text{ s.t. } a^\top W a = 1 \qquad \text{(ESL 4.16),} “a generalized eigenvalue problem, with a given by the largest eigenvalue of W^{-1}B” — identical in form to Mode A’s S_W^{-1}S_B w=\lambda w (B,W are ESL’s names for S_B,S_W, and B+W=T, the total covariance). ESL notes Fisher “arrived at this decomposition via a different route, without referring to Gaussian distributions at all,” yet it lands on the same discriminant directions — the two derivations agree (phase0/disagreements.md: LDA Fisher criterion and w\propto S_W^{-1}(m_1-m_2) match ESL §4.3; no flags). One subtlety ESL flags: the least-squares/Fisher route fixes the direction but the Gaussian route is needed to set the intercept (cut-point) — for two classes the two agree only when N_1=N_2 (ESL eq. 4.11 and following).
